# Data Source Note

Primary source selected for the project:

Kaggle — **Public Transportation Usage Dataset**
https://www.kaggle.com/code/amith1707/eda-transits-utilities-demo/input

The published dataset description states that it contains 569,400 rows, 88 columns, hourly observations across London, New York, Berlin, Tokyo, Paris and Singapore, with transit modes including bus, metro, rail, tram, lrt, ferry and light rail. It includes boarding count, occupancy, delay and other mobility features.

Important: the source description explicitly characterizes the dataset as a simulated, GTFS-inspired public-transport dataset. In the final report, describe it as an **online public dataset suitable for an academic prototype**, not as official government ridership data.
